## Android (APK et émulateur) — bloqué
- `flutter build apk --debug` échoue avant toute compilation : le Flutter installé ici (3.50.0) exige Gradle ≥ 9.3.1 (template : Gradle 9.5.0, AGP 9.3.1, Kotlin 2.4.20) ; le projet est en Gradle 8.13, AGP 8.11.1, Kotlin 2.2.20. Avec `--android-skip-build-dependency-validation`, le build échoue ensuite sur une incompatibilité d'API de l'AGP (`ApplicationExtension.getDefaultConfig()`).
- Conséquence : l'application Android n'a pas pu être construite ni lancée avec ce Flutter. Les parcours de la Task 5 (téléchargement, partage, moteur, navigateur, archive, envoi, stats) sont **non testés**. Aucun AVD n'a été démarré (l'AVD `ComiX_Design` existe, image android-35).
- Deux issues : migrer le projet Android vers AGP 9 / Gradle 9.5 / Kotlin 2.4 (changement de build, risqué pour les plugins), ou installer en parallèle un Flutter plus ancien compatible avec Gradle 8.13 (téléchargement d'environ 1 Go).
