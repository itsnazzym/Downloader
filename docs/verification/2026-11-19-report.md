- Deux issues : migrer le projet Android vers AGP 9 / Gradle 9.5 / Kotlin 2.4 (changement de build, risqué pour les plugins), ou installer en parallèle un Flutter plus ancien compatible avec Gradle 8.13 (téléchargement d'environ 1 Go).

Désactivé quand Tor est activé. Tests : 12 nouveaux.
